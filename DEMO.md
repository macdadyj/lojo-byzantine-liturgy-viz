# Demo

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints. For a production build:

```bash
npm test
npm run build
npm run preview
```

## Suggested first path

1. Start on **Gathering in the church**. You are in the narthex, looking east through the nave to the iconostas. People are seated. Click **Table of preparation** in the place list and read the note, then come back with step 1 in the list.
2. Press the Right arrow twice to reach **Blessed is the kingdom**. The view moves to the altar. The priest stands there. The people answer “Amen.”
3. Continue to **Little Entrance**. The camera rises in the west of the nave. The deacon walks with the Gospel book out the north deacon door, across the nave, and back through the Royal Doors. A ribbon on the floor shows the whole route.
4. Switch to **Free look** and drag to orbit the iconostas. Arrow keys still change the step. Switch back to **Follow liturgy** before the next jump.
5. In the step list, open **Great Entrance**. The deacon leads and the priest follows with the gifts from the table of preparation, through the nave, to the altar.
6. Open **The epiklesis**. The faithful bow. Then **Holy Communion**, where people come to the solea, then **Dismissal and antidoron**. The last step distinguishes antidoron from the Holy Eucharist.
7. Press Home to return to the gathering, or End to return to the dismissal.
8. Narrow the window to a phone width. The step list scrolls in a short pane, the church view stacks above the text, and Previous / Next stay reachable.

Keyboard: Left / Up and Right / Down move one step. Home and End jump. Buttons under the view are focusable. In Free look, drag orbits, right-drag pans, and the wheel zooms.
