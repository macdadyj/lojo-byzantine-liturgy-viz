# Demo

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints. For a production build:

```bash
npm test
npm run build
npm run preview
```

## Suggested first path

1. Start on **Gathering in the church**. The narthex, nave, and iconostas are highlighted. Click **Table of preparation** in the place list and read the note, then come back with step 1 in the list.
2. Press the Right arrow twice to reach **Blessed is the kingdom**. The highlight moves to the altar. The people answer “Amen.”
3. Continue to **Little Entrance**. A dotted path leaves by the north deacon door and returns through the Royal Doors. Click those doors on the plan.
4. In the step list, jump to **Great Entrance**. The path now runs from the table of preparation, through the nave, to the altar. Read what the faithful hear as the gifts pass.
5. Open **The epiklesis**, then **Holy Communion**, then **Dismissal and antidoron**. The last step returns the highlight to the solea, the nave, and the narthex, and distinguishes antidoron from the Holy Eucharist.
6. Press Home to return to the gathering, or End to return to the dismissal.
7. Narrow the window to a phone width. The step list scrolls in a short pane, the plan stacks above the text, and Previous / Next stay reachable.

Keyboard: Left / Up and Right / Down move one step. Home and End jump. Buttons and the plan rooms are focusable.
